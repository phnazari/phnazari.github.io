Quantizing Recurrent Language Models Is Easier Than You Think

Created on October 16, 2026

2026   ·   Deep-Learning   Quantization

The post-training quantization (PTQ) stack has been developed for softmax attention. For linear attention and hybrids, it remains underexplored. This work aims to change that. We differentiate between extra-state weight/activation (W/A) quantization and state quantization during decode, investigating how both differ from quantization in classical softmax attention. To store the linear attention state during decode, our final scheme LoReS combines value-axis grouping, stochastic rounding, and decay-based mixed precision.

Joint work with Neehal Tumma, Daniela Rus, and T. Konstantin Rusch.

Paper Code
Abstract

Linear recurrences are becoming an increasingly common building block in large language models, replacing the growing KV cache of softmax attention with a fixed-size recurrent state that enables efficient decoding. However, the quantization stack has largely been developed around softmax Transformers, whose numerical properties and inference state differ from those of recurrent models, motivating quantization schemes tailored to recurrences. We study how quantizing linear recurrences differs from quantizing softmax attention along two complementary axes. First, extra-state quantization concerns weights and activations outside the recurrent state, whose distributions are shaped indirectly by the sequence mixer during training. In controlled 1.3B models, we find that decayed recurrences develop much weaker residual outlier channels than softmax attention and are therefore easier to quantize without incoherence processing. Second, intra-state quantization concerns the recurrent state itself during decode, where repeated updates and recurrent decay create a different numerical problem from KV cache quantization. We use these insights to develop LoReS, a pipeline that combines value-axis scale grouping, decay-based mixed-precision allocation and stochastic rounding for low-bit recurrent state quantization. Across Qwen-3.5 9B, Nemotron-H 8B, and Kimi-Linear 48B-A3B, LoReS supports robust 8-bit state quantization and lower effective precision on shorter decode horizons. We implement LoReS in vLLM and demonstrate end-to-end decode speedups.

Architectural Differences: Linear vs. Softmax

Softmax attention and linear attention maintain fundamentally different objects for sequence mixing. While softmax attention appends keys and values to a growing KV cache, linear attention updates a fixed-size matrix state in place. This changes the quantization problem.

We differentiate between two quantization objectives. Extra-state quantization covers weights and activations. Its dependence on the sequence mixer is implicit. Intra-state quantization acts on the state stored during decode. Its dependence on the sequence mixer is explicit.

Extra-State Weight and Activation Quantization

We vary the sequence mixer in 1.3B models while keeping the surrounding backbone and training recipe fixed. All experiments in Table 1 use GPTQ with per-output-channel weight scales and dynamic activation scales. We test rotations of the residual stream and the inputs to the MLP down-projection and mixer output projection.

Decayed recurrences are robust

Without incoherence processing, decayed linear recurrences are more robust than softmax attention to W4A4 quantization. Keeping other recurrent degrees of freedom fixed, decay consistently helps, with diagonal decay working best. Applying all three rotations brings perplexity increases to similar levels across models. Robustness differences are thus mainly due to learned distributions, not error propagation under different algebraic properties of the sequence mixer itself.

Residual stream outliers

Softmax attention learns an outlier channel in its residual stream whose magnitude is approximately constant across tokens and layers. This channel coarsens the quantization grid, leading to larger quantization error. Decayed linear recurrences have weaker outliers. Across our mixer zoo, stronger outliers accompany larger W4A4 perplexity increases without rotations.

The nearly constant outlier channel acts as a bias on queries, keys and values. In softmax attention, the query/key bias can sharpen the attention distribution. Linear recurrences lack this softmax mechanism and instead use decay to focus on a few tokens. We hypothesize that this explains their weaker residual outliers.

LoReS: State Quantization

We organize our analysis around properties that distinguish recurrent state quantization from KV cache quantization:

  1. Scale grouping. The state has two channel axes, whereas a KV cache has a channel axis and a time axis.
  2. Mixed precision. Recurrent decay suppresses quantization error, inhibiting temporal error propagation.
  3. Rounding. The state is requantized after every decode step, so rounding errors can accumulate.
  4. Rotations. Rotations can reduce one-step error but worsen error propagation across steps.

The resulting quantization scheme, LoReS, keeps updates in full precision and quantizes the state stored between decode steps.

(1/4) Scale grouping

The recurrent state of linear attention has two feature axes. The KV cache only has one. We compare value- and key-axis grouping. Under round-to-nearest (RTN), value-axis (row) grouping is more robust. It is the LoReS default.

Mathematical details

Proposition (per-channel readout error). For a fixed state and unit-norm query, assume independent, uniform rounding errors within half a grid step. With \(\mathbf e=\mathbf E\mathbf q\),

\[\begin{aligned}\mathbb E[(e_i^{\mathrm{val}})^2]&=\frac{M_i^2}{12r^2},\\[0.5em]\mathbb E[(e_i^{\mathrm{key}})^2]&=\frac{\sum_j q_j^2 C_j^2}{12r^2}.\end{aligned}\]

Here \(M_i=\max_j|S_{ij}|\), \(C_j=\max_i|S_{ij}|\), and \(r=2^{b-1}-1\).

To interpret this result, recall that each value row of the state produces one output channel. Under value-axis grouping, the expected squared error in that output channel is proportional to the square of the row’s largest absolute entry. Under key-axis grouping, every channel has the same expected squared error, determined by the column ranges and the query. Large entries in one row can therefore set coarse quantization steps for other rows.

animation details

For a \(4\times4\) state and unit-norm query, we display the readout and predicted RMS rounding error:

\[o_i\pm\sigma_i=(\mathbf S\mathbf q)_i\pm\sqrt{\mathbb E[(\mathbf E\mathbf q)_i^2]}.\]

Here \(\mathbf E\) follows the independent uniform-error model in the proposition above.

(2/4) Mixed precision

Decay attenuates quantization error over time, so we allocate more bits to the slowest-decaying heads or channels.

Mathematical details

Proposition (decaying error). With identical initial states and fixed keys, values, and gates, assume \(\lVert\boldsymbol\alpha_t\rVert_\infty\le\alpha<1\). Delta correction, if used, has unit-norm keys and \(0<\beta_t<2\). Then accumulated state error satisfies

\[\lVert\mathbf E_t\rVert_F\le\sum_{\tau=1}^t\alpha^{t-\tau}\lVert\boldsymbol\varepsilon_\tau\rVert_F.\]

Each fresh quantization error \(\boldsymbol\varepsilon_\tau\) is suppressed exponentially as it propagates through later updates.

animation details

For one injected error, constant scalar decay, and no further rounding, we plot the surviving fraction:

\[\frac{\lVert\mathbf E_n\rVert_F}{\lVert\mathbf E_0\rVert_F}=\alpha^n.\]

(3/4) Rounding

Unlike RTN, stochastic rounding (SR) is conditionally unbiased. Under SR, interactions between errors from different quantization steps vanish in expectation, while RTN can reinforce them. LoReS uses SR with value grouping.

Mathematical details

Proposition (repeated quantization). Assume scalar decay, no delta correction, and keys, values, and gates fixed independently of rounding. Let \(\boldsymbol\varepsilon_\tau\) be fresh quantization error and \(\gamma_{\tau,t}=\prod_{j=\tau+1}^t\alpha_j\). For RTN and conditionally unbiased SR,

\[\begin{aligned} \lVert\mathbf E_t^{\mathrm{RTN}}\rVert_F^2 &=\sum_{\tau=1}^t\gamma_{\tau,t}^2\lVert\boldsymbol\varepsilon_\tau^{\mathrm{RTN}}\rVert_F^2\\ &\quad+2\!\sum_{1\le\tau<s\le t}\!\gamma_{\tau,t}\gamma_{s,t}\bigl\langle\boldsymbol\varepsilon_\tau^{\mathrm{RTN}},\boldsymbol\varepsilon_s^{\mathrm{RTN}}\bigr\rangle_F,\\[0.8em] \mathbb E\!\left[\lVert\mathbf E_t^{\mathrm{SR}}\rVert_F^2\right] &=\sum_{\tau=1}^t\gamma_{\tau,t}^2\mathbb E\!\left[\lVert\boldsymbol\varepsilon_\tau^{\mathrm{SR}}\rVert_F^2\right]. \end{aligned}\]

RTN can reinforce errors across steps. Under SR, these cross terms vanish in expectation.

animation details

After 100 synthetic scalar updates \(S_t=\alpha S_{t-1}+a v_tk_t\) on a fixed grid, we plot the remainder from the proposition:

\[R_t=E_t^2-\sum_{\tau=1}^t\alpha^{2(t-\tau)}\varepsilon_\tau^2.\]

Here \(E_t=\widehat S_t-S_t\). A fresh error \(\varepsilon_\tau\) survives as \(\gamma_{\tau,t}\varepsilon_\tau=\alpha^{t-\tau}\varepsilon_\tau\). Squaring gives the exponent \(2(t-\tau)\). Each trajectory contributes one RTN value and the mean of SR values.

(4/4) Rotations

Random Hadamard rotations reduce quantization reconstruction error. This benefit need not persist under repeated state quantization.

animation details

For a group \(G\) of 64 scalar recurrences sharing a scale, we compare two scale sources over 200 SR updates:

\[\begin{aligned} s_{G,t}^{\mathrm{noisy}}&=\frac{\lVert\mathbf S_t+\alpha\mathbf E_{t-1}\rVert_\infty}{r},\\[0.5em] s_{G,t}^{\mathrm{copy}}&=\frac{\lVert\mathbf S_t\rVert_\infty}{r}. \end{aligned}\]

Here \(\mathbf S_t\) is the unquantized state, \(\mathbf E_{t-1}\) is accumulated error, and \(r=2^{b-1}-1\) for \(b\) bits. Earlier errors affect the noisy scale. Using an unquantized copy removes this dependence, as in the paper’s experiment. We plot \(s_{G,t}\) and \(\lVert\widehat{\mathbf S}_t-\mathbf S_t\rVert_2\), with identical writes and SR draws.

Query alignment

Queries can suppress state quantization error by placing little weight on the affected dimensions. Rotations can weaken this suppression. This need not increase readout error, but we observe such increases in some of our experiments.

\[a=d_k\,\frac{\mathbb E\lVert\boldsymbol\varepsilon\mathbf q\rVert_2^2}{\mathbb E\lVert\boldsymbol\varepsilon\rVert_F^2}.\]

Here \(d_k=8\), \(\mathbf q\) has unit norm, \(\boldsymbol\varepsilon\) is fresh rounding error, and expectations are over SR. Results

Accuracy

INT8 states preserve most of the accuracy of FP32 states in Qwen-3.5 9B, Nemotron-H 8B, and Kimi-Linear 48B-A3B. Larger losses generally appear with 4-bit weights.

animation details

The tabs select the paper’s measured benchmark results for three hybrid models. Each table compares weight, activation, and state precisions. Highlighted rows use INT8 states.

Lower state precision

Allocating precision by decay lets us use 5 effective state bits for Qwen-3.5 and 5.5 for Nemotron-H on GSM8K with less than a 5% relative accuracy drop from FP32 states.

Speedup

State-quantization speedups grow with batch size. Weight-quantization gains are largest at small batches. The two therefore complement each other.
