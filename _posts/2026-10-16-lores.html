The post-training quantization (PTQ) stack has been developed for softmax attention. What changes when we replace it with a linear recurrence?

Joint work with Neehal Tumma, Daniela Rus, and T. Konstantin Rusch.

Paper Code

Softmax attention and linear attention maintain fundamentally different objects for sequence mixing. While softmax attention appends keys and values to a growing KV cache, linear attention updates a fixed-size matrix state in place:

Softmax attention stores the growing KV cache \(\mathbf S_t=(\mathbf K_{1:t},\mathbf V_{1:t})\). Each step appends a key–value pair and applies softmax attention over the cache:

\[\mathbf S_t=\mathbf S_{t-1}.\mathrm{append}(\mathbf k_t,\mathbf v_t),\qquad\mathbf o_t=\mathbf S_t.\mathrm{attend}(\mathbf q_t).\]

Linear attention, in its simplest form, updates a fixed-size state and reads it with the query:

\[\mathbf S_t=\mathbf S_{t-1}+\mathbf v_t\mathbf k_t^{\top},\qquad\mathbf o_t=\mathbf S_t\mathbf q_t,\]

where \(\mathbf S_t\in\mathbb R^{d_v\times d_k}\). Modern recurrent mixers combine decay, write gating, and delta correction:

\[\mathbf S_t=\mathbf S_{t-1}\,\class{lr-decay}{\operatorname{diag}(\boldsymbol\alpha_t)}\,\class{lr-delta}{\bigl(\mathbf I-\delta\beta_t\mathbf k_t\mathbf k_t^\top\bigr)}+\class{lr-gate}{\beta_t}\,\mathbf v_t\mathbf k_t^\top.\]

Decay controls what the state retains, write gating scales the new key–value update, and delta correction adjusts the stored association along the current key. In our notation, the indicator \(\class{lr-delta}{\delta\in\{0,1\}}\) is architecture specific and turns delta correction on or off.

The two attention variants thus maintain different objects. This changes the quantization problem. We differentiate between two objectives.

  • Extra-state quantization covers weights and activations (W/A). The mixer shapes their distributions during training, so its effect is implicit.
  • Intra-state quantization acts on the state stored during decode. The recurrence propagates quantization error through later updates, so its effect is explicit.

Extra-State Weight and Activation Quantization

To study how W/A quantization differs between linear attention and softmax attention, we vary the sequence mixer in 1.3B models while keeping the surrounding backbone and training recipe fixed.

Decayed recurrences are robust

Without incoherence processing, decayed linear recurrences are more robust than softmax attention to W4A4 quantization. Using ranndom Hadamard rotations brings perplexity increases to similar levels across models. In particular, the increased robustness of decayed linear recurrences seems to be a consequence of the learned W/A distributions.

Weight and activation quantization results

Residual stream outliers are the cause

Softmax attention learns an outlier channel in its residual stream whose magnitude is approximately constant across tokens and layers. This channel coarsens the activation quantization grid, leading to larger quantization error. Decayed linear recurrences have weaker outliers, making them more robust to activation quantization.

The nearly constant outlier channel acts as a bias on queries, keys and values. In softmax attention, the query/key bias can sharpen the attention distribution. Linear recurrences lack this softmax mechanism and instead use decay to focus on a few tokens.

Intra-State Quantization

Having discussed extra-state quantization above, in this section we organize our analysis around properties that distinguish recurrent state quantization from KV cache quantization:

  1. Scale grouping. The state has two channel axes, whereas a KV cache has a channel axis and a time axis.
  2. Mixed precision. Recurrent decay suppresses quantization error, inhibiting temporal error propagation.
  3. Rounding. The state is requantized after every decode step, so rounding errors can accumulate.
  4. Rotations. Rotations can reduce one-step error but worsen error propagation across steps.

(1/4) Scale grouping

The recurrent state of linear attention has two feature axes. The KV cache only has one. We thus compare value- and key-axis for recurrent state quantization, with the former defining one scale group per value-dimension of the state (i.e., per row), and the latter defining one scale group per key-dimension (i.e., per column).

Since the state is read out per value-channel, the key-channels span the recurrence-internal space. In particular, a large output channel represented by a large value-channel can coarsen the grids of all quantization groups under key-axis grouping. We thus find that, by default, value-axis grouping is more robust than key-axis grouping.

Mathematical details and interactive example

Proposition (per-channel readout error). For a fixed state and unit-norm query, assume independent, uniform rounding errors within half a grid step. With \(\mathbf e=\mathbf E\mathbf q\),

\[\begin{aligned}\mathbb E[(e_i^{\mathrm{val}})^2]&=\frac{M_i^2}{12r^2},\\[0.5em]\mathbb E[(e_i^{\mathrm{key}})^2]&=\frac{\sum_j q_j^2 C_j^2}{12r^2}.\end{aligned}\]

Here \(M_i=\max_j|S_{ij}|\), \(C_j=\max_i|S_{ij}|\), and \(r=2^{b-1}-1\).

Under value-axis grouping, the expected squared error in that output channel is proportional to the square of the row’s largest absolute entry. Under key-axis grouping, every channel has the same expected squared error, determined by the column ranges and the query. Large entries in one row can therefore set coarse quantization steps for other rows.

(2/4) Mixed precision

With keys, values, and gates fixed, the state quantization error follows

\[ \mathbf E_t=\underbrace{\mathbf E_{t-1}\,\class{lr-decay}{\operatorname{diag}(\boldsymbol\alpha_t)}\,\class{lr-delta}{\bigl(\mathbf I-\delta\beta_t\mathbf k_t\mathbf k_t^\top\bigr)}}_{\text{propagated earlier error}}+\underbrace{\boldsymbol\varepsilon_t\rlap{.}}_{\text{fresh rounding error}} \]

Here \(\mathbf E_t\) is the accumulated difference between the quantized and full-precision states, and \(\boldsymbol\varepsilon_t\) is the fresh error introduced by quantization at step \(t\).

Decay suppresses earlier quantization errors over time. We therefore allocate more bits to the slowest-decaying heads or channels.

Mathematical details and interactive example

Proposition (decaying error). With identical initial states and fixed keys, values, and gates, assume \(\lVert\class{lr-decay}{\boldsymbol\alpha_t}\rVert_\infty\le\class{lr-decay}{\alpha}<1\). Delta correction, if used, has unit-norm keys and \(0<\class{lr-delta}{\beta_t}<2\). Then accumulated state error satisfies

\[\lVert\mathbf E_t\rVert_F\le\sum_{\tau=1}^t\class{lr-decay}{\alpha^{t-\tau}}\lVert\boldsymbol\varepsilon_\tau\rVert_F.\]

Each fresh quantization error \(\boldsymbol\varepsilon_\tau\) is suppressed exponentially as it propagates through later updates.

\[\frac{\lVert\mathbf E_n\rVert_F}{\lVert\mathbf E_0\rVert_F}=\class{lr-decay}{\alpha^n}.\]

(3/4) Rounding

Under RTN, rounding errors from different steps can reinforce each other. Stochastic rounding (SR) is conditionally unbiased, so these interactions vanish in expectation.

Mathematical details and interactive example

Proposition (repeated quantization). Assume scalar decay, no delta correction, and keys, values, and gates fixed independently of rounding. Let \(\boldsymbol\varepsilon_\tau\) be fresh quantization error and \(\class{lr-decay}{\gamma_{\tau,t}}=\prod_{j=\tau+1}^t\class{lr-decay}{\alpha_j}\). For RTN and conditionally unbiased SR,

\[\begin{aligned} \lVert\mathbf E_t^{\mathrm{RTN}}\rVert_F^2 &=\sum_{\tau=1}^t\class{lr-decay}{\gamma_{\tau,t}}^2\lVert\boldsymbol\varepsilon_\tau^{\mathrm{RTN}}\rVert_F^2\\ &\quad+2\!\sum_{1\le\tau<s\le t}\!\class{lr-decay}{\gamma_{\tau,t}}\class{lr-decay}{\gamma_{s,t}}\bigl\langle\boldsymbol\varepsilon_\tau^{\mathrm{RTN}},\boldsymbol\varepsilon_s^{\mathrm{RTN}}\bigr\rangle_F,\\[0.8em] \mathbb E\!\left[\lVert\mathbf E_t^{\mathrm{SR}}\rVert_F^2\right] &=\sum_{\tau=1}^t\class{lr-decay}{\gamma_{\tau,t}}^2\mathbb E\!\left[\lVert\boldsymbol\varepsilon_\tau^{\mathrm{SR}}\rVert_F^2\right]. \end{aligned}\]

RTN can reinforce errors across steps. Under SR, these cross terms vanish in expectation.

animation details

After 100 synthetic scalar updates \(S_t=\class{lr-decay}{\alpha} S_{t-1}+a v_tk_t\) on a fixed grid, we plot the remainder from the proposition:

\[R_t=E_t^2-\sum_{\tau=1}^t\class{lr-decay}{\alpha^{2(t-\tau)}}\varepsilon_\tau^2.\]

A fresh error \(\varepsilon_\tau\) survives as \(\class{lr-decay}{\gamma_{\tau,t}}\varepsilon_\tau=\class{lr-decay}{\alpha^{t-\tau}}\varepsilon_\tau\). Squaring gives the exponent \(2(t-\tau)\). Each trajectory contributes one RTN value and the mean of SR values.

(4/4) Rotations

Random Hadamard rotations reduce quantization reconstruction error. This benefit need not persist under repeated state quantization.

Scale feedback loops

Quantization scales are computed from an already noisy state. A larger scale coarsens the grid and can introduce larger rounding errors, which can raise the next scale again. Deriving scales from an unquantized copy removes this feedback.

animation details

For a group \(G\) of 64 scalar recurrences sharing a scale, we compare two scale sources over 200 SR updates:

\[\begin{aligned} s_{G,t}^{\mathrm{noisy}}&=\frac{\lVert\mathbf S_t+\class{lr-decay}{\alpha}\mathbf E_{t-1}\rVert_\infty}{r},\\[0.5em] s_{G,t}^{\mathrm{copy}}&=\frac{\lVert\mathbf S_t\rVert_\infty}{r}. \end{aligned}\]

Here \(\mathbf S_t\) is the unquantized state, \(\mathbf E_{t-1}\) is accumulated error, and \(r=2^{b-1}-1\) for \(b\) bits. Earlier errors affect the noisy scale. Using an unquantized copy removes this dependence, as in the paper’s experiment. We plot \(s_{G,t}\) from both sources, with identical writes and SR draws.

Results

We instantiate these findings as LoReS, which stores recurrent states on unrotated integer grids using value-axis grouping, symmetric absmax scales, and stochastic rounding. INT8 is the default, with decay-based mixed precision assigning fewer bits to faster-decaying heads or channels. We combine LoReS with weight and activation quantization for end-to-end evaluation.

Accuracy

INT8 states preserve most of the accuracy of FP32 states in Qwen-3.5 9B, Nemotron-H 8B, and Kimi-Linear 48B-A3B. Larger losses generally appear with 4-bit weights.

Lower state precision

Allocating precision by decay lets us use 5 effective state bits for Qwen-3.5 and 5.5 for Nemotron-H on GSM8K with less than a 5% relative accuracy drop from FP32 states.

Speedup

State-quantization speedups grow with batch size. Weight-quantization gains are largest at small batches. The two therefore complement each other.
